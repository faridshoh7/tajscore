# Эмблемы клубов Лигаи Олӣ

Сюда кладутся логотипы таджикских клубов. Сайт подхватывает их сам, без
перезапуска сервиса (папка перечитывается раз в минуту).

## Как назвать файл

`.png`, `.svg`, `.webp`, `.jpg`, `.jpeg`. Регистр букв в имени не важен.

## Требования к картинке

- **Квадрат**, примерно 200×200 px и больше. Меньше 96 px будет мылить на
  странице команды, где эмблема показывается крупно.
- **Прозрачный фон** (PNG или SVG) — лучший вариант: эмблема одинаково
  хорошо смотрится и в тёмной, и в светлой теме. Если фон белый, сайт
  подложит под него светлую плашку, чтобы логотип не «висел» в темноте.
- Не обрезайте эмблему по краям — вокруг герба нужен небольшой воздух.
- Вес одного файла до ~200 КБ.

## Проверка

После добавления файлов:

```bash
cd /home/tajscore/tajscore
venv/bin/python scripts/check_logos.py
```

Скрипт покажет, у каких клубов эмблема уже своя, а у каких пока берётся
из API. Файл с неизвестным именем он тоже назовёт — так сразу видно опечатку.

Если файла для клуба нет, сайт показывает логотип из API-Football, поэтому
докладывать эмблемы можно по одной.
