# Реклама на Tajscore

Сюда кладутся файлы рекламы (видео и картинки), а список показов описывается
в **`data/ads.json`**. Сервер перечитывает этот файл на лету — сохранили,
обновили страницу, реклама сменилась. Перезапускать ничего не нужно.

---

## 1. Где реклама показывается

Один блок на всём сайте — **сразу под лентой дат, над списком матчей**.
Так сделано у Sofascore и Flashscore: человек видит рекламу первым экраном,
но она не разрывает список матчей и уезжает вверх при прокрутке.
На телефоне — там же, между датами и первой лигой.

Если включённой рекламы нет, на этом месте остаётся маленькая серая
плашка `AD · Реклама` высотой 54–64 px. Место не «прыгает».

---

## 2. Точные размеры — делайте ровно так

| Версия | Размер места (CSS) | Пропорция | Файл делайте | Макс. вес |
|---|---|---|---|---|
| **Компьютер** (ширина экрана ≥ 861 px) | **1200 × 171 px** | **7 : 1** | **2400 × 342 px** (@2x) | видео ≤ 6 МБ |
| **Телефон** (ширина экрана ≤ 860 px) | **640 × 240 px** | **8 : 3** (2.67 : 1) | **1280 × 480 px** (@2x) | видео ≤ 3 МБ |

Важное про пропорции: блок растягивается по ширине экрана, а высота считается
из пропорции. Поэтому **главное — попасть в пропорцию 7:1 (компьютер) и
8:3 (телефон)**, а не в пиксели один в один. Ролик 2400×342 на узком ноутбуке
просто уменьшится целиком, ничего не обрежется.

### Требования к видео

- формат **MP4 (H.264, `yuv420p`)**, дополнительно можно положить `.webm`;
- длительность **6–15 секунд**, ролик крутится по кругу;
- **без звука** — браузеры запрещают автозапуск со звуком, дорожка всё равно
  будет отключена (`muted`), не рассчитывайте на неё;
- 25–30 кадров в секунду;
- обязательно сделайте **постер** (первый кадр в `.jpg`) того же размера —
  его видно, пока грузится видео, и на слабом интернете.

Готовый рецепт пережатия (ffmpeg):

```bash
# компьютер: 2400x342
ffmpeg -i source.mp4 -vf "scale=2400:342:force_original_aspect_ratio=increase,crop=2400:342" \
  -an -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 26 -movflags +faststart \
  static/ads/moyareklama-desktop.mp4
ffmpeg -i static/ads/moyareklama-desktop.mp4 -vframes 1 -q:v 3 \
  static/ads/moyareklama-desktop.jpg

# телефон: 1280x480
ffmpeg -i source.mp4 -vf "scale=1280:480:force_original_aspect_ratio=increase,crop=1280:480" \
  -an -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 26 -movflags +faststart \
  static/ads/moyareklama-mobile.mp4
ffmpeg -i static/ads/moyareklama-mobile.mp4 -vframes 1 -q:v 3 \
  static/ads/moyareklama-mobile.jpg
```

### Картинка вместо видео

Можно и просто картинку — `.jpg`, `.png` или `.webp`, те же размеры
(2400 × 342 и 1280 × 480). Укажите `"type": "image"`.

## 3. Как добавить рекламу

1. Положите файлы в эту папку (`static/ads/`).
2. Откройте `data/ads.json` и добавьте блок в список `items`.
3. Сохраните файл. Всё.

```json
{
  "enabled": true,
  "items": [
    {
      "id": "somon",
      "enabled": true,
      "title": "Somon Air — билеты в Дубай",
      "link": "https://somonair.com",
      "weight": 2,
      "start": "2026-10-01",
      "end": "2026-10-31",
      "desktop": {
        "type": "video",
        "src": "/static/ads/somon-desktop.mp4",
        "poster": "/static/ads/somon-desktop.jpg"
      },
      "mobile": {
        "type": "video",
        "src": "/static/ads/somon-mobile.mp4",
        "poster": "/static/ads/somon-mobile.jpg"
      }
    }
  ]
}
```

### Что означает каждое поле

| Поле | Обязательно | Что делает |
|---|---|---|
| `enabled` (верхний) | да | `false` — вся реклама на сайте выключена, везде заглушка |
| `id` | нет | любое короткое имя, нужно только вам |
| `enabled` (внутри блока) | нет | `false` — этот блок не показывается, но остаётся в файле |
| `title` | нет | подпись для незрячих и `alt` картинки |
| `link` | нет | куда ведёт клик. Пусто — блок некликабельный |
| `weight` | нет | вес в ротации: `2` показывается вдвое чаще, чем `1` |
| `start` / `end` | нет | даты `ГГГГ-ММ-ДД`, вне этого окна блок не показывается. `null` — без ограничения |
| `desktop` | да | креатив для компьютера: `type` (`video`/`image`), `src`, `poster` |
| `mobile` | нет | креатив для телефона. Не указали — возьмётся `desktop` |

Блоков может быть сколько угодно: они чередуются случайно с учётом `weight`,
а на странице сменяются каждые 30 секунд.

---

## 4. Проверить, что всё правильно

Откройте в браузере `https://ваш-сайт/api/ads` — сервер покажет,
какие блоки он считает активными сегодня, и продублирует размеры места.
Если ваш блок там не появился — проверьте `enabled`, даты `start`/`end`
и что путь `src` начинается с `/static/ads/`.

Битый JSON сайт не уронит: в этом случае реклама просто не покажется,
а в логах появится строка `data/ads.json не прочитан`.
